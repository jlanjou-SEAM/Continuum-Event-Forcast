AWIPS EDEX Access

AWIPS (Advanced Weather Interactive Processing System) is a meteorological display and analysis package originally developed by the National Weather Service and Raytheon. NSF Unidata provides a slightly modified version of the package tailored for our primary user base of US Academic institutions, their faculty, and students.

The AWIPS EDEX (Environmental Data EXchange) is a specialized data server designed for the needs of forecasters using the AWIPS CAVE (Common AWIPS Visualization Environment) visualization client. You can learn more about how the AWIPS components fit together in the NSF Unidata AWIPS manual.

NSF Unidata runs a publicly-accessible EDEX server on the National Science Foundation's Jetstream2 Cloud for educational and research use. NSF Unidata's EDEX server is integrated with the Science Gateway project, a community-directed virtual hub to enable learning and support research for current and future Earth Systems Science students, educators, and professionals.

To access this server, install NSF Unidata's AWIPS CAVE client, point CAVE to edex-cloud.unidata.ucar.edu. This server is also accessible via NSF Unidata's Python-AWIPS as well.
