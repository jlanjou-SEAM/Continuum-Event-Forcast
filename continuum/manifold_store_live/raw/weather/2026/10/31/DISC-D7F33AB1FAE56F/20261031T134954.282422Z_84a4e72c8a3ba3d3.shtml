  NCEP Meteorological Assimilation Data Ingest System (MADIS)

What's Here - Version 4.0.12!


May 2025 - Version 4.0.12


  • Increase mesonet max records 30% to 500,000
  • Change HADS database key from GOES ID to NWSLI
  • Add sfcdump latest arriving time filter for the last 30 to 60 minutes
  • In the MADIS API the OMO hourly precipitation was changed from hourly accumulation (PCP1H) to ASOS hourly accumulation (PCP1HA). ASOS start of the hour is minute 40-60, depending on the site.
  • Add timestamps to web pages
  • Increase MadisAircraft/MadisAircraftPublic to display the last 30 days
  • Remove the use of the local disk use by the MadisAircraft/MadisAircraftPublic wildfly display
  • Fixed acarsProfile reports to include all aircraft profiles
  • SNOTEL monthly precip data fix
  • Add null data and java errors checks to SNOTEL hourly, daily, and monthly data
  • New API version 4.7
  • MADIS using large memory model
  • SNOTEL ingest only runs on OPS
  • Change web map display to use USGS National map.
  • Add null data and java errors checks to SNOTEL hourly, daily, and monthly data
  • Increase Vaisala pulls timeout to 30 seconds

  • NWS Access to Aircraft Weather Data
  • NWS meteorologists at WFOs, CWSUs, AWC, AAWU, RFCs, and National Centers have access to aircraft weather data from over 3,000 commercial aircraft flying in North America.
  • Access for the past 25+ years was from a page hosted by GSL at https://ruc.noaa.gov/amdar/java
  • That web site was deactivated October 1st and will no longer be available.
  • The web site to access these data is now hosted at IDP, and requires a login and password issued by
  • MADIS. To request one, go to https://madis.ncep.noaa.gov/data_application.shtml
  • While waiting for a login and password, you can access data from 125 aircraft equipped with water vapor sensors at https://madis-data.ncep.noaa.gov/MadisAircraftPublic/ This web site is in the public domain, so can be shared with the private sector and public. (Remember that this web site does not have wind and temperature data from the other 3,000 aircraft available on the password restricted site).
  • If there are problems with the MADIS web page during regular daytime hours, please report it to NCEP.List.MADIS_Support@noaa.gov and madis-support@noaa.gov After hours support is from sdm@noaa.gov
  • Questions about web page functionality can be sent to madis-support@noaa.gov

    January 2015 - MADIS Transition Completed

    MADIS has transitioned to operations at the NWS National Centers for Environmental Prediction (NCEP) Central Operations (NCO), with archive capabilities provided by the National Environmental Satellite, Data, and Information Service's (NESDIS) National Climatic Data Center (NCDC). NCO will provide operational and MADIS help desk support at madis-support@noaa.gov. The MADIS development team at NOAA's Office of Oceanic and Atmospheric Reasearch (OAR) Earth System Research Laboratory (ESRL) Global Systems Division (GSD) will provide enhancements and software maintenance support.
