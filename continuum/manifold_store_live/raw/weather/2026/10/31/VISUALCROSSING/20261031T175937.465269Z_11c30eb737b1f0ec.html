Weather Data FAQs

What types of weather data are available through the Visual Crossing Weather API?

We offer comprehensive data for a range of use cases, which include:

  • Temperature
  • Humidity
  • Precipitation
  • Wind speed
  • Solar energy
  • Degree days
  • Soil temperature and moisture
  • Marine weather
  • Historical forecast data
  • Real-time data
  • Air quality data

How do I specify locations when making a Weather API request?

You can specify a location using address, ZIP code, city name, or latitude/longitude.

How frequently is the weather data updated in the API?

Certain weather stations update every 15 to 30 minutes, while others update hourly. Visual Crossing uses interpolation to provide hyperlocal and regularly updated data to users.

Can the Weather API handle large-scale or bulk data requests?

Yes. Starting with our metered plans, users can access an unlimited number of records with unlimited concurrency. The Timeline LLX Weather API enables users to query 5,000 records per minute.

Can I request multiple locations or date ranges in a single API call?

The Weather API allows you to request a date range or multiple dates in a single API using this format: /timeline/[location]/[date1]/[date2] 

You can also use a dynamic date period to query for a given date range in relation to the current date.

Our Multiple Location Timeline Weather API allows users to query for multiple locations in the same request.
