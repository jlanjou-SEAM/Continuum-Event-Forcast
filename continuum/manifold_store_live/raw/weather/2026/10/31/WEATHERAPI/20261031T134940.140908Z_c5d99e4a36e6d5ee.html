Weather API Documentation

WeatherAPI.com provides access to free weather and geo data via a JSON/XML restful API. It allows developers to create desktop, web and mobile applications using this data very easy.

We provide following data through our API:

  • Real-time weather
  • 14 day weather forecast
  • Historical weather
  • Marine Weather and Tide Data
  • Future Weather (Upto 365 days ahead)
  • Daily and hourly intervals
  • Pollen forecast (Pro+ plan and above) New
  • 15 min intervalNew (Enterprise only)
  • Astronomy
  • Time zone
  • Sports
  • Weather Maps New
  • Location data
  • Search or Autocomplete API
  • Weather Alerts
  • Air Quality Data
  • Bulk Request
  • Solar Irradiance
  • Solar PV Energy Forecast (Business plan and above) New
  • Agriculture: growing degree days, crop water use, spray windows, disease and frost risk (Business plan and above) New
  • Evapotranspiration (Enterprise)
  • Wind at 100m (Enterprise) New
  • Pollen History (Enterprise) New

Quick start

  1. Sign up free and copy your API key from your account.
  2. Call any endpoint with your key, for example current weather for London:
    https://api.weatherapi.com/v1/current.json?key=YOUR_API_KEY&q=London
  3. Explore every endpoint and parameter in the guides below, or try requests in the API Explorer.

APIs

Realtime API

Current weather API (current.json): temperature, feels like, wind, humidity, pressure, UV and optional air quality for any location, as JSON or XML.

Forecast API

Forecast API (forecast.json): up to 14 days of daily and hourly weather, astronomy, alerts and air quality. Parameters, response fields and examples.

History API

History API (history.json): hourly and daily historical weather for any date since 1 January 2010. Parameters, response fields and examples.

Alerts API

Alerts API (alerts.json): government-issued weather warnings for the requested location, with headline, severity, areas, effective and expiry times.

Marine API

Marine API (marine.json): wave height, swell, water temperature and tide data for coastal and offshore locations, up to 7 days ahead.

Future API

Future API (future.json): 3-hourly weather for a date between 14 and 300 days in the future, for event and travel planning. Parameters and examples.

Solar Energy API New

Solar PV energy forecast API: hourly and daily power and energy for your system for up to 14 days, from GHI, DNI and DHI irradiance. Business plan and above.

Agriculture API New

Agriculture API: growing degree days, ET0 and crop water use, spray windows, frost, disease and blight risk for up to 14 days. Business plan and above.

Search/Autocomplete API

Search/Autocomplete API (search.json): find matching cities and towns as the user types, with id, name, region, country, latitude and longitude.

IP Lookup API

IP Lookup API (ip.json): city, region, country, continent, coordinates and time zone for an IPv4 or IPv6 address. Fields and example response.

Astronomy API

Astronomy API (astronomy.json): sunrise, sunset, moonrise, moonset, moon phase and illumination for any location and date.

Time Zone API

Time Zone API (timezone.json): time zone id and current local time for a city, coordinates, postcode or IP address.

Sports API

Sports API (sports.json): upcoming football, cricket and golf events with stadium, country, tournament and start time, for weather-aware apps.
