Files for automated data services

The Bureau of Meteorology makes a number of real-time forecast, warning and observation products and analysis charts available via the web and Anonymous FTP.

These products are free to access and are not for commercial use. Please see the Anonymous FTP Service user guide for more information on using the service.

When users access these products anonymously, the Bureau cannot track the usage of any particular product thus it is not possible to directly contact customers affected by service changes. Customers requiring support, service continuity and access to more secure Cloud (S)FTP services should make use of the Bureau's Registered User Services.

Unless otherwise stated, products available via this service are subject to the default terms of use in the Bureau's Copyright Notice.

Please note:

  • The Bureau does not guarantee the availability of information on the FTP site.
  • Use of data should be in accordance with the copyright notice and disclaimer.

Full product listing

View the full list of all products available via anonymous FTP.

Forecasts

The following products are routinely produced for each state and territory:

  • State or Territory Forecast
  • Précis Forecast
  • City Forecast
  • Town Forecast
  • District Forecast (N/A for Northern Territory)
  • Coastal Waters and Local Waters Forecasts

Some other products are specific to their respective state or territory, and may be produced seasonally, such as some fire weather products.

Please see the text forecasts user guide for more information.

Warnings

The Bureau of Meteorology makes warnings available via the web and the BOM Weather app.

The Bureau offers RSS feeds for state-based warnings.

The National Warnings Summary page provides a list of current warnings and automatically refreshes whenever a warning is issued.

There are links on this page to the warning content, with the product code included in the link.

Warnings available via Anonymous FTP are listed in the Anonymous FTP product listing.

Please see the warning products user guide for more information.

The Bureau provides its observational data in a number of formats for use as a data feed.

72-hour station based observational products are available in xml, axf and json formats.

Radar

Radar images for individual radars are issued every five-minutes.

Static radar transparencies and overlays are available in a separate directory.

Please see the radar images user guide for more information.

Satellite

Satellite images from the Himawari-9 satellite are issued every ten minutes in JPG and GeoTIFF formats. File names include timestamps for these images.

Please see the satellite images (JPG format) and satellite images (GeoTIFF format) user guides for more information.

UV

UV Index and sun protection times are provided in text and graphical products.
